# Universal Social Gateway

Modular gateway for social media automation.

## Quickstart
```bash
git clone https://github.com/fsix7115-arch/universal-social-gateway
cd universal-social-gateway
npm install
node dist/index.js doctor
```

## Troubleshooting
- **Build Error?** This project uses standard dependencies. If you see errors, ensure Node.js 18+ is installed: `node -v`
- **Missing Platforms?** We provide skeletons for Instagram, Facebook, and Twitter.
